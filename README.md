# Lingo Work 🌍 — Language Learning App

Lingo Work is a language-learning application designed to help users improve their language skills through vocabulary flashcards, pronunciation practice, quizzes, and progress tracking.

## ✨ Features

- 🔐 User registration and login
- 🌍 Learn French, Spanish, German, and Italian with English translations
- 🗂️ Interactive vocabulary flashcards
- 🔊 Pronunciation practice using browser text-to-speech
- 📝 Quizzes to test your knowledge
- 📈 Learning progress and streak tracking
- 👤 User profile

## 🛠️ Technologies Used

- **Backend:** Python, FastAPI
- **Database:** SQLite, SQLAlchemy
- **Frontend:** HTML, CSS, JavaScript
- **Authentication:** JWT and bcrypt
- **Pronunciation:** Web Speech API

## 🚀 Getting Started

1. Clone or download this repository.
2. Open the project folder in Visual Studio Code.
3. Open a terminal in the backend directory.
4. Install the dependencies listed in the project.
5. Start the FastAPI backend using the project's configuration.
6. Open the frontend using the appropriate local web server.

Refer to the project's source code and configuration for the exact setup commands.
